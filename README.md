# React Accessible Search Demo

A small React showcase of accessible search patterns using local sample data.

## Live demo

https://rony-890.github.io/react-accessible-search-demo/

## Included

- A visible search label and associated help text
- Local results with loading, empty, and example error/retry states
- Result announcements and visible keyboard focus

The demo sends no search requests and contains no client-specific content.

## Run and check

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```
